Le langage CSS

Mettre en forme une page web : sélecteurs, boîtes, Flexbox et Grid — niveau BTS CIEL.

À RETENIR
CSS (Cascading Style Sheets) décrit l'apparence d'une page HTML : couleurs, tailles, positionnement, mise en page. Le "C" de CSS (cascade) fait référence aux règles de priorité qui déterminent quel style s'applique quand plusieurs règles concernent le même élément.

1. Introduction : à quoi sert le CSS et où l'écrire

Le CSS s'applique à des éléments HTML via des règles, composées d'un sélecteur (qui cibler) et d'un bloc de déclarations (propriété: valeur) :

p {
  color: navy;
  font-size: 16px;
}

Trois façons d'intégrer du CSS à une page, par ordre de priorité croissante :

MéthodeExempleUsage recommandé
Externe<link rel="stylesheet" href="style.css">La méthode à privilégier : CSS réutilisable sur plusieurs pages, mis en cache par le navigateur
Interne<style> p { color: navy; } </style> dans le <head>Pour une page unique et autonome (démo, email)
Inline<p style="color: navy;">À éviter : mélange contenu et style, impossible à réutiliser, priorité très élevée qui complique la maintenance

2. Sélecteurs de base

p { color: navy; }              /* tous les éléments p */
.important { color: red; }      /* tous les éléments avec class="important" */
#titre { font-size: 2em; }      /* l'élément unique avec id="titre" */
* { margin: 0; }                /* sélecteur universel : tous les éléments */
h1, h2, h3 { font-weight: bold; } /* groupement : plusieurs sélecteurs, une seule règle */
SélecteurCible
elementToutes les balises de ce type
.classeTous les éléments ayant cette classe (réutilisable)
#idL'élément unique ayant cet id
*Tous les éléments de la page

3. Sélecteurs avancés et pseudo-classes

div p { color: red; }        /* descendant : tout p à l'intérieur d'un div, à n'importe quel niveau */
div > p { color: red; }      /* enfant DIRECT uniquement */
h1 + p { margin-top: 0; }    /* le p immédiatement après un h1 */
input[type="email"] { }      /* sélecteur d'attribut */

a:hover { color: orange; }       /* au survol de la souris */
li:first-child { font-weight: bold; } /* premier enfant de son parent */
li:nth-child(2) { color: blue; }      /* le 2e enfant précisément */
input:focus { border-color: blue; }   /* champ actif (cliqué dedans) */

p::first-letter { font-size: 2em; }   /* pseudo-élément : cible une PARTIE de l'élément */
.box::before { content: "→ "; }       /* insère du contenu avant l'élément */
ATTENTION — pseudo-classe vs pseudo-élément
Une pseudo-classe (un seul :, ex : :hover) cible un état d'un élément existant. Un pseudo-élément (deux :, ex : ::before) crée ou cible une sous-partie de l'élément qui n'existe pas forcément dans le HTML.

4. Couleurs et unités de mesure

Format de couleurExemple
Mot-clécolor: tomato;
Hexadécimalcolor: #ff6347;
RGBcolor: rgb(255, 99, 71);
RGBA (avec transparence)color: rgba(255, 99, 71, 0.5);
HSL (teinte, saturation, luminosité)color: hsl(9, 100%, 64%);
UnitéTypeSignification
pxAbsoluePixel — taille fixe, ne s'adapte pas
%RelativePourcentage de la taille du parent
emRelativeMultiple de la taille de police de l'élément parent
remRelativeMultiple de la taille de police de la racine (html) — plus prévisible que em
vw / vhRelativePourcentage de la largeur / hauteur de la fenêtre (viewport)
À RETENIR
rem est généralement préférée à em pour les tailles de police : comme em se cumule à chaque niveau d'imbrication (un enfant dans un enfant voit sa taille multipliée plusieurs fois), les calculs deviennent vite imprévisibles. rem reste toujours relative à une seule référence fixe.

5. Le modèle de boîte (box model)

Chaque élément HTML est représenté comme une boîte rectangulaire, composée de 4 couches, de l'intérieur vers l'extérieur :

.boite {
  width: 200px;
  padding: 20px;       /* espace intérieur, entre le contenu et la bordure */
  border: 2px solid black;
  margin: 10px;        /* espace extérieur, entre la boîte et ses voisines */
}
CoucheRôle
ContentLe contenu lui-même (texte, image...)
PaddingEspace intérieur, entre le contenu et la bordure — a la couleur de fond de l'élément
BorderLa bordure, visible
MarginEspace extérieur, transparent, entre cette boîte et ses voisines
ATTENTION — box-sizing
Par défaut (box-sizing: content-box), width ne concerne que le contenu : la largeur totale affichée est width + padding + border. Avec box-sizing: border-box (très recommandé, souvent appliqué globalement avec * { box-sizing: border-box; }), width inclut le padding et la bordure — beaucoup plus intuitif à calculer.

Raccourcis pour margin/padding : margin: 10px; (les 4 côtés), margin: 10px 20px; (haut/bas puis gauche/droite), margin: 10px 20px 5px 15px; (haut, droite, bas, gauche — sens horaire).

6. Texte et polices

p {
  font-family: "Segoe UI", Arial, sans-serif;
  font-size: 1rem;
  font-weight: bold;
  font-style: italic;
  text-align: center;
  line-height: 1.6;
  text-decoration: underline;
  text-transform: uppercase;
}
PropriétéRôle
font-familyListe de polices par ordre de préférence, avec une police générique en secours (sans-serif, serif, monospace)
font-weightGraisse : normal, bold, ou valeur numérique (100 à 900)
line-heightHauteur de ligne — une valeur sans unité (ex : 1.6) est un multiple de la taille de police, recommandé pour la lisibilité
text-alignAlignement horizontal du texte : left, center, right, justify

7. Positionnement : display et position

Valeur de displayComportement
blockPrend toute la largeur disponible, saut de ligne avant/après (ex : div, p)
inlineNe prend que la largeur nécessaire, pas de saut de ligne ; width/height sans effet (ex : span, a)
inline-blockComme inline (pas de saut de ligne) mais accepte width/height/margin vertical
noneL'élément disparaît complètement de la page (contrairement à visibility: hidden, qui laisse un espace vide)
Valeur de positionComportement
staticComportement par défaut, dans le flux normal
relativeDéplacé (avec top/left/etc.) par rapport à sa position normale, mais laisse son emplacement d'origine "réservé"
absolutePositionné par rapport à son ancêtre positionné le plus proche (relative/absolute/fixed), sorti du flux normal
fixedPositionné par rapport à la fenêtre du navigateur, reste visible même en scrollant
stickySe comporte comme relative, puis devient fixed une fois un seuil de scroll atteint
À RETENIR
z-index détermine l'ordre d'empilement des éléments positionnés qui se chevauchent (plus la valeur est grande, plus l'élément est "au-dessus") — il n'a d'effet que sur un élément dont position n'est pas static.

8. Flexbox : aligner en une dimension

.conteneur {
  display: flex;
  flex-direction: row;         /* row (défaut) ou column */
  justify-content: center;     /* alignement sur l'axe principal */
  align-items: center;         /* alignement sur l'axe perpendiculaire */
  flex-wrap: wrap;             /* autorise le retour à la ligne */
  gap: 16px;                   /* espace entre les éléments */
}
PropriétéValeurs utiles
justify-contentflex-start, center, flex-end, space-between, space-around
align-itemsflex-start, center, flex-end, stretch
flex: 1Sur un enfant : lui fait occuper l'espace disponible restant
À RETENIR
Le duo display: flex; justify-content: center; align-items: center; sur un conteneur est la façon moderne standard de centrer un élément horizontalement et verticalement — bien plus simple que les anciennes méthodes.

9. Grid et mise en page responsive

.conteneur {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;   /* 3 colonnes égales */
  grid-template-columns: repeat(3, 1fr); /* équivalent, plus lisible */
  gap: 16px;
}

/* Media query : adapte le style selon la largeur d'écran */
@media (max-width: 600px) {
  .conteneur {
    grid-template-columns: 1fr;  /* 1 seule colonne sur mobile */
  }
}
FlexboxGrid
Une seule dimension (ligne OU colonne)Deux dimensions (lignes ET colonnes) simultanément
Idéal pour aligner des éléments dans une barre, une listeIdéal pour une mise en page globale de page (galerie, tableau de bord)
ATTENTION
Une media query ne modifie jamais le HTML : elle applique des règles CSS différentes selon des conditions (largeur d'écran, orientation...). L'approche recommandée est mobile-first : écrire le CSS de base pour mobile, puis ajouter des @media (min-width: ...) pour les écrans plus grands.

10. Cascade et spécificité + hors programme

Quand plusieurs règles CSS ciblent le même élément avec des propriétés contradictoires, le navigateur choisit selon la spécificité (plus précis l'emporte), puis, à spécificité égale, selon l'ordre d'apparition (le dernier l'emporte) :

SélecteurPoids (approximatif)
Élément (p)1
Classe (.ma-classe), attribut, pseudo-classe10
Id (#mon-id)100
Style inline (style="...")1000
!importantPasse outre presque toute la cascade normale
ATTENTION
!important doit rester exceptionnel : il casse la logique normale de la cascade et rend le CSS difficile à maintenir (le seul moyen de le contrer est un autre !important encore plus spécifique).

11. Transitions et animations + hors programme

.bouton {
  background: tomato;
  transition: background 0.3s ease, transform 0.3s ease;
}
.bouton:hover {
  background: darkred;
  transform: scale(1.05);
}

@keyframes apparition {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}
.carte {
  animation: apparition 0.5s ease-out;
}

transition anime le passage entre deux états (ex : normal → survol). @keyframes + animation permettent des animations plus riches, avec plusieurs étapes, indépendantes d'une interaction utilisateur.

12. Variables CSS (custom properties) + hors programme

:root {
  --couleur-principale: #e3b341;
  --espacement: 16px;
}

.bouton {
  background: var(--couleur-principale);
  padding: var(--espacement);
}
.bouton:hover {
  background: color-mix(in srgb, var(--couleur-principale) 80%, black);
}
À RETENIR
Contrairement aux préprocesseurs comme Sass, les variables CSS natives (--nom) sont vivantes : elles peuvent être modifiées dynamiquement en JavaScript ou selon le contexte (ex : un mode sombre défini en redéfinissant les mêmes variables dans un autre sélecteur), sans recompilation.

13. Méthodologie BEM et organisation du CSS + hors programme

Sur un vrai projet, un CSS mal organisé devient vite ingérable. La méthodologie BEM (Block Element Modifier) structure le nommage des classes pour éviter les conflits :

<div class="carte carte--mise-en-avant">
  <h2 class="carte__titre">Titre</h2>
  <p class="carte__texte">Texte</p>
</div>

.carte { }                 /* Block */
.carte__titre { }          /* Element : carte__element */
.carte--mise-en-avant { }  /* Modifier : carte--modificateur */

Cette convention rend le CSS plus prévisible en évitant les sélecteurs imbriqués trop profonds et les conflits de spécificité. Sur de plus gros projets, des frameworks comme Tailwind CSS (classes utilitaires) ou Bootstrap (composants prêts à l'emploi) sont aussi très répandus en entreprise.
