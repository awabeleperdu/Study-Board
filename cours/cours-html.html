Le langage HTML

Structurer une page web : balises, sémantique, formulaires — niveau BTS CIEL.

À RETENIR
HTML (HyperText Markup Language) n'est pas un langage de programmation : c'est un langage de balisage. Il décrit la structure et le sens du contenu d'une page (quel texte est un titre, quel texte est un lien...), pas son apparence — c'est le rôle du CSS — ni son comportement — c'est le rôle du JavaScript.

1. Introduction : structure d'un document HTML

Un document HTML est un fichier texte composé de balises (tags), généralement par paires : une balise ouvrante <p> et une balise fermante </p>, qui entourent un contenu. L'ensemble forme un élément. Certaines balises n'ont pas de contenu et se referment elles-mêmes (balises "orphelines") : <img>, <br>, <input>.

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Ma page</title>
</head>
<body>
  <h1>Bonjour !</h1>
  <p>Ceci est un paragraphe.</p>
</body>
</html>
LigneRôle
<!DOCTYPE html>Indique au navigateur qu'il s'agit d'un document HTML5 (obligatoire, en première ligne)
<html lang="fr">Élément racine ; l'attribut lang déclare la langue du contenu (accessibilité, traduction automatique)
<head>Métadonnées de la page, invisibles à l'écran (voir section 2)
<body>Contenu visible de la page
À RETENIR
Les éléments HTML s'imbriquent en respectant une hiérarchie stricte : un élément ouvert en dernier doit être fermé en premier (<p><strong>texte</strong></p> est valide, <p><strong>texte</p></strong> ne l'est pas).

2. Le <head> : métadonnées de la page

BaliseRôle
<title>Titre affiché dans l'onglet du navigateur et les résultats de recherche
<meta charset="UTF-8">Encodage des caractères (permet d'afficher les accents correctement)
<meta name="viewport" content="width=device-width, initial-scale=1">Adapte l'affichage aux écrans mobiles (indispensable pour un site responsive)
<link rel="stylesheet" href="style.css">Lie une feuille de style CSS externe
<meta name="description" content="...">Description affichée dans les résultats des moteurs de recherche

3. Texte et sémantique de base

<h1>Titre principal</h1>
<h2>Sous-titre</h2>
<p>Un paragraphe de texte normal.</p>
<strong>Texte important</strong> et <em>texte en emphase</em>
<br> <!-- saut de ligne -->
<hr> <!-- ligne de séparation horizontale -->

<ul>
  <li>Élément de liste non ordonnée</li>
  <li>Un autre élément</li>
</ul>

<ol>
  <li>Premier élément numéroté</li>
  <li>Deuxième élément</li>
</ol>
BalisesUsage
h1 à h6Titres hiérarchisés, du plus important (h1) au moins important (h6)
pParagraphe
ul / ol / liListe non ordonnée (puces) / ordonnée (numéros) / élément de liste
strong vs bstrong = important sémantiquement (lu différemment par un lecteur d'écran) ; b = gras purement visuel, sans signification
em vs iMême logique : em a un sens (emphase), i est purement visuel (italique)
span vs divspan : conteneur en ligne (inline), sans saut de ligne. div : conteneur de bloc, avec saut de ligne avant/après
ATTENTION — hiérarchie des titres
N'utilisez jamais un h3 juste parce qu'il est "plus petit" visuellement : les niveaux de titres doivent suivre la structure logique du document (un seul h1 par page, puis h2 pour les sections, h3 pour les sous-sections...). C'est essentiel pour l'accessibilité et le référencement.

4. Liens et navigation

<a href="https://exemple.com">Lien externe</a>
<a href="contact.html">Lien relatif vers une autre page du site</a>
<a href="#section2">Aller à la section 2 (ancre)</a>
<a href="https://exemple.com" target="_blank" rel="noopener">Ouvrir dans un nouvel onglet</a>
<a href="mailto:contact@exemple.com">Envoyer un email</a>

<h2 id="section2">Section 2</h2> <!-- cible de l'ancre ci-dessus -->
Type de lienExemple
Absoluhref="https://exemple.com/page" — adresse complète
Relatifhref="page.html" ou href="dossier/page.html" — par rapport au fichier actuel
Ancrehref="#id-cible" — vers un élément portant cet id sur la même page
À RETENIR
target="_blank" ouvre le lien dans un nouvel onglet ; il faut alors ajouter rel="noopener" pour des raisons de sécurité (la nouvelle page ne peut pas manipuler la page d'origine via window.opener).

5. Images et médias

<img src="photo.jpg" alt="Description de l'image" width="400">

<video src="video.mp4" controls width="500"></video>

<audio src="son.mp3" controls></audio>

<iframe src="https://exemple.com" width="600" height="400"></iframe>
AttributRôle
srcChemin vers le fichier (relatif ou URL absolue)
altTexte alternatif : lu par les lecteurs d'écran, affiché si l'image ne charge pas. Obligatoire pour l'accessibilité
controlsAffiche les contrôles de lecture (lecture/pause/volume) pour audio/vidéo
width / heightDimensions ; les préciser évite que la page "saute" pendant le chargement
ATTENTION
<img> est une balise orpheline (pas de </img>). Un alt="" vide est acceptable pour une image purement décorative, mais un alt manquant est une erreur d'accessibilité.

6. Tableaux

<table>
  <thead>
    <tr>
      <th>Jour</th>
      <th>Matière</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Lundi</td>
      <td>Maths</td>
    </tr>
    <tr>
      <td colspan="2">Journée banalisée</td>
    </tr>
  </tbody>
</table>
BaliseRôle
tableConteneur du tableau
trLigne (table row)
thCellule d'en-tête (mise en gras et centrée par défaut)
tdCellule de donnée
thead / tbodyRegroupent respectivement l'en-tête et le corps du tableau (structure sémantique)
colspan / rowspanFusionne une cellule sur plusieurs colonnes / lignes
ATTENTION
Un tableau HTML sert à présenter des données tabulaires (emploi du temps, résultats...), jamais à faire de la mise en page générale d'un site — c'est le rôle du CSS (flexbox, grid).

7. Formulaires

<form action="/envoyer" method="post">
  <label for="nom">Nom :</label>
  <input type="text" id="nom" name="nom" required placeholder="Votre nom">

  <label for="email">Email :</label>
  <input type="email" id="email" name="email" required>

  <label for="age">Âge :</label>
  <input type="number" id="age" name="age" min="15" max="99">

  <label for="matiere">Matière préférée :</label>
  <select id="matiere" name="matiere">
    <option value="maths">Maths</option>
    <option value="nsi">NSI</option>
  </select>

  <label for="message">Message :</label>
  <textarea id="message" name="message" rows="4"></textarea>

  <input type="checkbox" id="cgu" name="cgu">
  <label for="cgu">J'accepte les conditions</label>

  <button type="submit">Envoyer</button>
</form>
Type d'inputUsage
textTexte libre sur une ligne
emailVérifie automatiquement le format d'un email
passwordMasque la saisie
numberValeur numérique, avec min/max
checkbox / radioCase à cocher / bouton radio (choix unique parmi un groupe de même name)
dateSélecteur de date natif du navigateur
submitBouton qui envoie le formulaire
À RETENIR
L'attribut for d'un <label> doit correspondre à l'id du champ associé : cliquer sur le label active alors automatiquement le champ (essentiel pour l'accessibilité et l'ergonomie mobile). L'attribut name, lui, sert à identifier le champ côté serveur lors de l'envoi du formulaire.

method="get" envoie les données visibles dans l'URL (à éviter pour des données sensibles) ; method="post" les envoie dans le corps de la requête, invisibles dans l'URL.

8. HTML sémantique (HTML5)

Depuis HTML5, des balises spécifiques remplacent les <div> génériques pour donner un sens aux grandes zones de la page :

<header>
  <h1>Mon site</h1>
  <nav>
    <a href="#accueil">Accueil</a>
    <a href="#contact">Contact</a>
  </nav>
</header>

<main>
  <article>
    <h2>Titre de l'article</h2>
    <p>Contenu principal...</p>
  </article>
  <aside>
    <p>Contenu secondaire (ex : liens connexes)</p>
  </aside>
</main>

<footer>
  <p>© 2026 Mon site</p>
</footer>
BaliseRôle
headerEn-tête de la page ou d'une section (logo, titre, parfois la nav)
navBloc de liens de navigation principaux
mainContenu principal, unique par page
sectionRegroupement thématique de contenu, généralement avec son propre titre
articleContenu autonome, qui aurait du sens seul (un article de blog, un commentaire)
asideContenu connexe, en marge du sujet principal
footerPied de page ou de section
À RETENIR
Ces balises n'ont aucun style visuel particulier par défaut (elles se comportent comme des div) : leur intérêt est uniquement sémantique — accessibilité (navigation au clavier/lecteur d'écran) et référencement (les moteurs de recherche comprennent mieux la structure de la page).

9. Attributs globaux et bonnes pratiques

AttributRôle
idIdentifiant unique sur toute la page (cible d'ancre, de CSS ou de JS)
classCatégorie réutilisable sur plusieurs éléments (ciblage CSS/JS)
data-*Attribut personnalisé pour stocker une donnée exploitable en JavaScript (ex : data-id="42")
langLangue du contenu (accessibilité, traduction)
titleInfo-bulle affichée au survol
ATTENTION — id vs class
Un id ne doit apparaître qu'une seule fois dans toute la page ; une class peut être réutilisée sur autant d'éléments que nécessaire. Utiliser deux fois le même id est une erreur de validité HTML, même si le navigateur l'affiche quand même.

Un document HTML se vérifie avec le validateur officiel du W3C (voir Ressources) : il signale les balises mal fermées, les attributs obligatoires manquants, etc.

10. Formulaires avancés et accessibilité + hors programme

<input type="text" pattern="[A-Za-z]{2,}" title="2 lettres minimum, sans chiffre" required>
<input type="tel" pattern="0[0-9]{9}" placeholder="0612345678">
<input type="text" aria-label="Rechercher sur le site">
<button aria-label="Fermer la fenêtre">✕</button>
AttributRôle
patternExpression régulière que la valeur doit respecter (validation native, sans JavaScript)
requiredRend le champ obligatoire avant l'envoi du formulaire
aria-labelFournit un libellé accessible quand aucun texte visible n'explique l'élément (ex : un bouton icône)
aria-hidden="true"Cache un élément purement décoratif aux lecteurs d'écran

11. Images responsives + hors programme

<img src="photo-800.jpg"
     srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1200.jpg 1200w"
     sizes="(max-width: 600px) 400px, 800px"
     alt="Description">

<picture>
  <source media="(max-width: 600px)" srcset="mobile.jpg">
  <img src="desktop.jpg" alt="Description">
</picture>

srcset laisse le navigateur choisir la meilleure résolution d'image selon l'écran, économisant de la bande passante sur mobile. <picture> permet en plus de changer complètement d'image (pas juste de résolution) selon la taille d'écran.

12. Lier CSS et JavaScript + hors programme

<head>
  <link rel="stylesheet" href="style.css">      <!-- CSS externe -->
  <style> body { margin: 0; } </style>           <!-- CSS interne -->
</head>
<body>
  ...
  <script src="script.js" defer></script>         <!-- juste avant </body> ou avec defer -->
</body>
À RETENIR
defer télécharge le script en parallèle du reste de la page mais ne l'exécute qu'une fois le HTML entièrement chargé — c'est la méthode recommandée. Sans defer, un <script> placé dans le <head> bloque l'affichage de la page pendant son téléchargement et son exécution.

13. SEO et métadonnées avancées + hors programme

<meta name="description" content="Cours de HTML pour BTS CIEL">
<link rel="canonical" href="https://exemple.com/page">
<link rel="icon" href="favicon.png">

<!-- Open Graph : aperçu personnalisé sur les réseaux sociaux -->
<meta property="og:title" content="Titre affiché lors d'un partage">
<meta property="og:image" content="apercu.jpg">
<meta property="og:description" content="Description du partage">

Les balises Open Graph (préfixe og:) contrôlent l'aperçu affiché quand un lien de la page est partagé sur Facebook, Discord, LinkedIn, etc. — sans elles, le réseau social devine (souvent mal) quoi afficher.
